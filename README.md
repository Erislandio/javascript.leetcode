# 🚀 LeetCode Solutions - JavaScript & TypeScript

Este repositório contém minhas resoluções para diversos desafios do [LeetCode](https://leetcode.com/), implementadas em **JavaScript** e agora com suporte para **TypeScript**.

O objetivo deste projeto é documentar meu progresso, praticar algoritmos e estruturas de dados, e aprimorar minhas habilidades de resolução de problemas em JS/TS.

## 🛠️ Como Executar

### Executar JavaScript
```bash
node nome_do_arquivo.js
```

### Executar TypeScript
Para rodar os arquivos TS, primeiro instale as dependências com `npm install`, depois use:
```bash
npm run dev nome_do_arquivo.ts
```

### Exemplo:
```bash
npm run dev mergeTwoLists.ts
```

Alguns arquivos já incluem um `console.log` básico para testar os resultados.
